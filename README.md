# Марк и Полина · 26 июня 2027

Первый русскоязычный макет свадебного приглашения. HTML, CSS и JavaScript без сборки и зависимостей.

## Локальный просмотр

Запустите `python -m http.server 4173 --bind 127.0.0.1` в этой папке и откройте http://127.0.0.1:4173.

## Что готово

- Адаптивная молочно-оливковая страница, место, ссылки на карты, программа без вымышленных времён, палитра и ночёвка.
- Демонстрационные обращения: общее, пара, гость с неизвестным +1.
- Отдельные ответы каждого гостя: участие, ночёвка, транспорт, свободные места, город выезда, напитки, питание.
- Имя +1 необязательно. При отказе вопросы о поездке и ночёвке скрыты и исключены из проверки формы.

## Перед рассылкой гостям

Это НЕ готовый сервис RSVP: форма ничего не сохраняет. Выбор примеров не является защищённой персонализацией. В клиентском коде только вымышленные гости.

Нужен сервер для приглашений по случайным непрогнозируемым токенам, чтения только соответствующей записи, валидации разрешённого числа гостей и сохранения/редактирования ответов. Реальные имена, токены и ответы не размещать в статических файлах или Git. Административный экспорт должен требовать отдельной авторизации. Не отправлять токены сторонним сервисам аналитики.

Уточнить площадку, программу, дресс-код, условия ночёвки, срок ответа и контакты. Добавить согласованные фото. Проверить точку на карте перед рассылкой. Настроить хостинг и при желании домен.

GitHub хранит исходный код. GitHub Pages подходит для статической страницы, но не предоставляет API хранения RSVP.
